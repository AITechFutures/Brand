# ATF brand assets

Logos, icons, colours and fonts for **ATF (AI Technology Futures Ltd)**.

**Download page:** https://aitechfutures.github.io/Brand/

## Contents

| Folder / file | What it is |
| --- | --- |
| `index.html` | The download page shown at the link above |
| `ATF_Brand_Assets/` | Logos: wide, compact and mark, in four colourways, as SVG, PNG and PDF; email signature logos and template; favicon and app icons; social images |
| `ATF_Icons_Starter/` | 32 icons (Material Symbols, Sharp, weight 500) as SVG and PNG in Future Blue, Logo Ink and white |
| `ATF_Brand_Assets.zip`, `ATF_Icons_Starter.zip` | Everything above as two downloads |

## Rules for this repository

- **Never rename, move or delete** files in `ATF_Brand_Assets/03_Email_Signature/`, `01_Web/` or `05_Social/`. Email signatures and web pages link to them directly.
- Add new files freely. After changing logo files, rebuild the two zips so the downloads stay in step.
- The repository is public: add nothing confidential.
