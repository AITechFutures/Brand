ATF brand assets (September 2026)
=================================
Full rules: see "ATF Brand Guidelines" (Claude doc).

00_Master_SVG       Vector masters (transparent, text outlined). Source for everything.
01_Web              SVG + PNG @1x/@2x, favicon.ico/.svg, apple-touch-icon, icon-192/512, og-share image
02_Documents        High-res transparent PNG + SVG for Word / PowerPoint / Google Docs
03_Email_Signature  2x PNG logos on white + ATF_email_signature.html template (Arial only, never SVG)
04_Print            Vector PDF for printers and signage
05_Social           LinkedIn banners, avatars, share image

File names: ATF_[lockup]_[descriptor]_[colourway]
  lockup      wide | compact | compact_plain | mark
  descriptor  applied (Applied Intelligence - corporate) | industrial (Industrial AI - commercial)
  colourway   colour-on-light | colour-on-dark | black | white   (mark: colour | black | white)

Colours: Future Blue #889CE7 | Tech Black #000000 | Logo Ink #121317 | Soft Light Gray #F3F3F3
         Industrial Gray #9EA0AD | Deep Future Blue #4F63B8 (text on light) | Text Gray #666874 (text on light)
Fonts:   Web - Bebas Neue / Montserrat 500-700 / Space Grotesk 400-500 / JetBrains Mono
         Word, PowerPoint, email - Arial (Consolas for data)
